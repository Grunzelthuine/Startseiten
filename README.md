# Startseiten

Startseiten mit Links zu Sebastians Apps, gehostet über Cloudflare Pages.

| Ordner | Adresse | Inhalt |
|---|---|---|
| `jagd/` | https://jg-thuine.pages.dev | Jagd Thuine, Hochsitze |

Jede Seite ist ein eigenes Cloudflare-Pages-Projekt mit *Build output directory* = Ordnername. Änderungen auf `main` werden automatisch veröffentlicht.

Die Startseiten enthalten nur Links. Der Schutz der Daten liegt in den Apps selbst (Passwort bzw. Konto).
